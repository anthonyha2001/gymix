# The marketing board

The team's memory. The main Claude session updates these files from the agents' work; agents only read them.
Every CSV opens in Google Sheets or Excel (File → Import) if you prefer a spreadsheet.

| File | What's in it |
|---|---|
| `tasks.csv` | Every task card and its status: to do, drafting, guardian, founder, approved, live |
| `calendar.csv` | Social posts: date, platform, hook, captions in each language, visual, status, link, results |
| `leads.csv` | Gyms to talk to and where each one is: new, contacted, replied, demo seen, visit, trial, paying, lost |
| `ads.csv` | Campaigns and ads with spend, clicks, demos, trials and the decision |
| `metrics.csv` | One row a week: the funnel from visits to paying gyms |
| `questions.md` | Everything marked `[TO CONFIRM]`, waiting for the founder |

Weekly work (plans, drafts, reports, SVG designs) goes in `marketing/work/<ISO week>/`.
